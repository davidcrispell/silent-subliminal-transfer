# J-lens disposition-transfer project

This project tests whether a transient, interaction-induced teacher state leaves
a subtle fingerprint in faithful paraphrases and whether training a
near-checkpoint student on those paraphrases installs a corresponding
disposition.

It is separate from, but informed by, the PolyPythia SL-mechanism project in
`../replications and experiments 1`.

## Canonical files

- `EXPERIMENTS.md` — append-only research ledger and standing hypotheses.
- `COMPUTE_BUDGET.md` — planning assumptions, run counts, and cost ranges.
- `configs/` — frozen experiment configurations.
- `scripts/` — executable experiment and analysis code.
- `runs/` — immutable run artifacts and compact reports.
- `notes/` — literature and design notes that are not primary results.

## Current status

Design and compute scoping. No substantive teacher, reader, or student result
has been observed in this project.
